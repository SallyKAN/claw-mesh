## v0.2 新增功能（3 项核心 + 3 项收尾）

### P0 — 核心（Day 1-4）

#### 1. Sync — 身份/记忆/Skills 跨机同步 ⭐ 核心差异化
这是 v0.2 的唯一重磅功能，也是 claw-mesh 区别于所有竞品的护城河。

同步范围：
- 身份文件：SOUL.md, IDENTITY.md, USER.md
- 记忆文件：MEMORY.md, memory/*.md
- Skills 目录：~/.claude/skills/ 下的 SKILL.md + 脚本

实现方案：
- Coordinator 做中转站，维护文件 manifest（path + sha256 + mtime）
- Node 每 30s pull manifest，对比本地 hash，增量下载变更文件
- 上传：node 检测本地文件变更 → push 到 coordinator → 广播给其他节点
- 冲突：双方都改了同一文件 → 保留双方（.conflict-{nodeId}）+ 通知 dashboard

API：
- `GET /api/v1/sync/manifest` — 获取当前文件清单
- `GET /api/v1/sync/file?path=xxx` — 下载单个文件
- `POST /api/v1/sync/push` — 上传文件变更
- `GET /api/v1/sync/status` — 同步状态（各节点最后同步时间）

新文件：
- `internal/sync/manifest.go` — 文件清单管理 + hash 计算
- `internal/sync/server.go` — coordinator 侧 sync API handlers
- `internal/sync/client.go` — node 侧 sync pull/push 逻辑
- `internal/sync/watcher.go` — 本地文件变更检测（fsnotify 或定时扫描）

工作量：3 天

## Demo 脚本（发布时录屏）

1. Mac Mini 启动 coordinator，打开 Dashboard，显示空 mesh
2. Linux `claw-mesh join` → Dashboard 显示新节点上线
3. Dashboard 聊天框发消息 → 自动路由到 Linux 的 OpenClaw → 回复显示
4. 在 Mac Mini 上编辑 SOUL.md → 30s 后 Linux 节点自动同步 → 验证文件一致
5. 在 Mac Mini 上添加一个 skill → Linux 自动获得 → 用该 skill 完成任务
6. 断开 Linux → Dashboard 显示离线 → 重连后自动补同步

## 核心差异化叙事

SwarmClaw = "多个独立 OpenClaw 的管理面板"
→ 每个 agent 独立运行，手动配置 gateway/SOUL.md/记忆

claw-mesh = "多台机器融合成一个 AI 助手"
→ `join` 一下就完事，身份和记忆自动同步，skills 自动共享

## 技术决策

- 语言：Go（单二进制分发）
- 同步：基于文件 hash 的增量同步，coordinator 做中转，不用 git/rsync
- 存储：文件系统（manifest.json），不引入数据库
- 前端：原生 HTML/JS，不引入框架
- 变更检测：优先 fsnotify，fallback 到定时扫描（30s）
